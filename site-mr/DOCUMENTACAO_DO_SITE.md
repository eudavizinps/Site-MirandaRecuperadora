# Documentacao do site MR Recuperadora de Credito

Este documento registra as principais entregas realizadas no site institucional da MR Recuperadora de Credito.

O projeto foi construido como um site estatico, com arquivos HTML, CSS, JavaScript e imagens locais. A estrutura principal fica em `outputs/`, permitindo abrir o site diretamente pelo arquivo `index.html` ou publicar os arquivos em uma hospedagem tradicional.
