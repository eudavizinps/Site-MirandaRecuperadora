# Documentacao do site MR Recuperadora de Credito

Este documento registra as principais entregas realizadas no site institucional da MR Recuperadora de Credito.

O projeto foi construido como um site estatico, com arquivos HTML, CSS, JavaScript e imagens locais. A estrutura principal fica em `outputs/`, permitindo abrir o site diretamente pelo arquivo `index.html` ou publicar os arquivos em uma hospedagem tradicional.

## Identidade visual

A identidade visual foi desenvolvida com predominancia de azul e branco, seguindo a solicitacao original da empresa. A marca utiliza a estrela de Davi azul como elemento visual principal e aplica o nome comercial Miranda Recuperadora de Credito no topo e no rodape.

O banner principal recebeu uma imagem institucional com atmosfera corporativa, mantendo foco em recuperacao de credito, resultados e profissionalismo. O texto principal comunica a proposta da empresa: recuperar creditos, reduzir inadimplencia e fortalecer resultados para os clientes.

## Navegacao e contatos

O topo do site organiza os links principais para Quem somos, Solucoes, Indicadores, Parcerias, Depoimentos e Contato. A area de contato possui opcoes para Trabalhe Conosco e Negocie seus debitos.

Os botoes comerciais foram configurados para WhatsApp, direcionando o visitante para os numeros definidos durante o desenvolvimento. O botao Setor Comercial encaminha para o contato comercial, enquanto o botao Negocie suas dividas encaminha para o atendimento de negociacao de debitos.

Tambem foram adicionados botoes para Facebook e LinkedIn, mantendo os links oficiais informados para a presenca digital da empresa.
