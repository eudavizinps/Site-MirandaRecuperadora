# Miranda Recuperadora de Crédito

Site institucional responsivo para apresentar a Miranda Recuperadora de Crédito com clareza e facilitar o contato de visitantes interessados nos serviços.

**[Acessar o site ↗](https://site-mirandarecuperadora.pages.dev/)**

## Sobre o projeto

A interface reúne a apresentação da empresa, informações sobre os serviços e caminhos de contato em uma navegação adaptada a diferentes tamanhos de tela. O visual foi desenvolvido com atenção à legibilidade e à confiança transmitida pela marca.

## Tecnologias

HTML, CSS e JavaScript.

## Estrutura do repositório

Os arquivos e a documentação do projeto estão na pasta [`site-mr`](./site-mr).
